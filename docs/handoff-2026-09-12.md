# TokenBar — Handoff completo (2026-09-12)

Monitor de tokens/assinaturas de IA para a menu bar do macOS, estilo CodexBar,
porém leve (≤40MB `phys_footprint`, CPU <0.5%) e com mais funcionalidades
(histórico+custo, alertas, multi-conta, analytics). Swift nativo construído
**sem Xcode** (só Command Line Tools), open source MIT, design portado 1:1 da
referência MIT (CodexBar/steipete — ver `LICENSE`/`NOTICE`).

- **Repo**: `~/Documents/Projetos/tokenbar` · branch `main` · tag `v1.0.0`
- **Status**: 1.0 completa + fixes pós-1.0 de UI (painel sem scrollbar, item
  da menu bar com logos funcionando). 579 testes / 92 suítes verdes, E2E v5
  com 81 checks, QA 6/6, Red Team 8/8.
- **Rodando**: app real em `build/TokenBar.app` na máquina do Felipe, com
  dados vivos (X:…% Z:…% U:…% K:…% com logos).

## 2. Arquitetura (módulos em `Sources/`)

- **TokenBarCore** — domínio: `ProviderDisplay`, `UsageWindow`, pricing
  (`pricing.json` versionado, custo ~USD, NULL≠0, não-retroativo), GRDB
  (SQLite WAL, migrations v1+v2: `daily_agg`, `settings`, `accounts`),
  watermark hwm dedupe na mesma transação, `AppDatabase` com
  `BundledPricingBox` **lazy** (ler pricing fora da main — fix do hang).
- **TokenBarProviders** — protocolo `UsageProvider`
  (`discoverAccounts`/`fetchUsage`/`ingestLocal`) com contrato de cursor;
  ingest incremental JSONL com cursor/hwm por conta. **10 providers**:
  claude `C` (local), codex `X` (wham/usage, epoch SEGUNDOS), gemini `G`
  (local, dedupe por id), zai `Z` (quota/limit, epoch MS), cursor `U`,
  openrouter `O`, qwen/alibaba `Q`, antigravity `V`, deepseek `D`, grok `K`.
  Endpoints portados da referência MIT com fonte citada.
- **TokenBarUI** — `SnapshotStore` (fonte única; render gate F1: só publica
  quando a string muda), painel (`ProviderPanelView` 310pt), chips,
  analytics, add-account, settings; `ProviderLogo` (SVGs C/X/G/Z + bitmaps
  rasterizados), `ProviderMenuBarLabel`, `ExtraWindowManager` (lifecycle de
  janelas extras), `E2EHeartbeat`.
- **tokenbar** — app: `MenuBarExtra` (.window) + `Settings` scene,
  scheduler adaptativo (300/60/30s, backoff ×2 teto 30min, jitter ±10%,
  single-flight), FSEvents+debounce para providers file-driven.
- **panelrender** (debug-only) — harness `ImageRenderer` para evidência do
  painel. **Não rasteriza NSImage** (logos somem no harness; válido para
  texto/layout). Modos: `panelrender <png>`, `--menulabel <prefix>`,
  lado-a-lado com referência.
- **genfixtures** — gerador de fixtures sintéticas.

Docs de decisão por fase: `docs/specs/` (design, data-sources, providers),
`docs/decisoes-f1..f5.md`, `docs/decisoes-ui-fixes-2026-09-12.md`, QA em
`docs/qa/` com evidências PNG.

## 3. Comandos do dia a dia

```bash
swift build                          # debug
./run-tests.sh                       # 579 testes (SEMPRE este; swift test puro quebra)
./scripts/make-app.sh release        # build/TokenBar.app (copia *.bundle, fail-loud)
open build/TokenBar.app              # rodar
./scripts/e2e.sh                     # E2E hermético (81 checks, TOKENBAR_E2E_DIR)
./scripts/ui-smoke.sh                # boot + item + toggle do painel + quit (AX-honesto)
./scripts/release.sh                 # release.zip + sha256 em build/
swift build --product panelrender && .build/debug/panelrender <png>
```

Relançar: `pkill -x tokenbar; sleep 1; open build/TokenBar.app`. Cuidado:
**nunca** matar por nome genérico além de `tokenbar` (ui-smoke usa nome
próprio `tokenbar-ui-smoke`; pkill por nome já matou binários de debug e
simulou "app morreu sem crash").

## 4. Verificação (Regra 9 — prova de conclusão)

- Teste verde só conta após confirmar que **cobre o requisito** (escopo da
  verificação = escopo do requisito). Proibido redefinir sucesso.
- **Render de UI exige verificação por PIXELS**: AX name ≠ pintura (o item
  da menu bar reportava string completa no AX enquanto não pintava).
- **Diff de pixels sempre da LARGURA TOTAL do bar** (monitor do Felipe é
  ultrawide 2560pt e o item realoca; região fixa dá falso negativo):
  ```bash
  screencapture -x -R0,0,2560,32 /tmp/with.png; pkill -x tokenbar; sleep 2
  screencapture -x -R0,0,2560,32 /tmp/without.png; cmp -s /tmp/{with,without}.png
  ```
  Depois localizar a banda (sips crop + cmp) e **olhar o PNG** (visão).
- AX desta máquina: `MenuBarExtra` .window cria janela ESCONDIDA no launch;
  painel não expõe conteúdo ao AX programático; System Events precisa
  indexar processo novo (poll com sleep). Interações internas do painel são
  cobertas por testes unitários + ui-smoke + QA manual.

## 5. Bugs históricos que ensinaram (não repetir)

1. **Hang no launch via `open`** (F4): bundles de recursos não copiados no
   .app → `Bundle.module` pendurava a main thread. Fix: make-app copia
   `*.bundle` fail-loud + pricing lazy fora da main. Se o app "roda mas não
   aparece nada": `sample <pid> 2` e olhar a main thread.
2. **SVG no label do MenuBarExtra quebra o status item** (2026-09-12):
   `Image(nsImage:)` vetorial media ~zero → item colapsava p/ ~1 par
   logo+valor ou não pintava. Fix: `Text` único com logos **bitmap 3x**
   (`ProviderLogo.bitmap`). Painel segue com SVG (imune).
3. **Janela extra travava o event loop** (fix painel): soltar o
   NSWindowController dentro de `windowWillClose` travava tudo
   ("nada que eu clico funciona"). Fix: `ExtraWindowManager` — release
   DEFERIDO p/ o próximo ciclo da main loop + `NSApp.activate` em todo show.
4. **Ingest concorrente duplicava** eventos: guard skip-if-busy; rollover
   F2 regrediu no refactor (ordem pós-needsFullRescan); overflow Int64
   saturante+cap 10^15; FIFO como credencial travava ciclo
   (FileKind.isRegularFile); dirs sobrepostos dobravam DB (guard com
   symlinks); contas inativas presas (união registry⊕ciclo).
5. **Confounder**: existe **CodexBar.app instalado** na máquina com item
   próprio `[logo]7%` (monitora o mesmo codex). Não confundir com o nosso
   item ao inspecionar screenshots.
6. **Hook Mimosa**: comandos Bash compostos que mencionam paths de script
   podem ser bloqueados como "escrita direta" (falso positivo) — separar
   em comandos simples.
